## Trigger

- The user asks for a skill or plugin name, tagline, or listing.

## Inputs

- The concept explains the job.
- The audience explains who will use it.
- Confirmed inputs, outputs, and capabilities define the listing claims.
- A selected name or naming preference limits the choices.

## What happens

1. The plugin asks up to three questions about the job, audience, and inputs and outputs when those details are missing.
2. It waits for answers and remembers them. It uses a name already selected by the user. If the request is complete, it proceeds.
3. For a naming request, it proposes three to five clear names and recommends one. It explains how the name describes the job.
4. It drafts the requested tagline, description, feature bullets, and usage steps from confirmed capabilities.
5. It includes a time estimate only when its basis is supplied. It labels an unmeasured value as an estimate.
6. It checks the text for clarity, repeated facts, and unsupported claims. It returns the requested copy.
7. If the user changes the concept or asks to revise one part, it updates the affected text without restarting intake.

## Outputs

- A name shortlist and recommendation when requested.
- A tagline, description, feature bullets, and usage steps in the chat.
- No repository, directory listing, or account setting is changed.
